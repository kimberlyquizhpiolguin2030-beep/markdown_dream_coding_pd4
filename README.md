## My Dream Coding Project: Ecotrack🌱
## Project overview
*Ecotrack* is an app designed to help users *track their daily* carbon footprint and make a small, sustainable choices that add up to a big impact. Its built using **html,CSS** - but one day, I want to expand it into a full web platform!
## Project Goals
- Build a user-friendly dashboard that tracks:

    - 🌿**Energy use**
    - 🚗*transportation impact*
    - 🍔*food consumption patterns*
    
- Display personalized reports using:
    
  - `console.log()` to debug progress
    ```
    if (carbon score< 50) {
        console.log("great job staying eco-friendly!");
        console.log("Let's find ways to reduce your footprint!");}
    ```
